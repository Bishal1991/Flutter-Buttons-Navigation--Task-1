# Project Overall description

## File Structure
this project contain 7 Dart files including main file. they are:
1. main.dart: which is the entry point of this project
2. login.dart: which is the first page to be visible when application run
3. signup.dart: which is a mockUp signUp page
4. home.dart: which contains 7 types of button 
5. profile.dart: which can be navigated from profile icon in the top right corner.
6. add.dart: which can be navigated into using filled tonal button
7. setting.dart: which can be navigated into using filled button

## Buttons
**Note:** the elevated button and text button is left unused in home.dart as they are already used in Login page and also because this project doesn't have enough page to route too.

### Project Requirement
Include at least:
1. Elevated Button
2. Filled Button
3. Filled Tonal Button
4. Outlined Button
5. Text Button
6. Icon Button
7. Floating Action Button
8. Button with Icon
9. At least one custom-styled button

Each button should have a meaningful action.
For example:
1. Add → Navigate to Add Screen
2. Profile → Navigate to Profile Screen
3. Settings → Navigate to Settings Screen
4. Back → Return to previous screen
5. Logout → Replace current screen with Login screen

### How i meet project requirements
I have my own custom styled elevated button in login.dart and signup.dart. In home.dart, i have every listed button with meaning functionality.
